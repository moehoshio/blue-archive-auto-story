# Templates live here. They are PNG screenshots cropped to a small unique UI element.
# See `bass capture` and tools/capture_template.py for an interactive way to produce them.
#
# Layout:
#   common/    confirm.png cancel.png close_x.png next.png ...
#   story/     auto_on.png auto_off.png menu_button.png clear_screen.png ...
#   battle/    sortie.png x1_speed.png x2_speed.png auto_on.png auto_off.png victory.png defeat.png result_next.png
#   menu/      home_indicator.png event_entry.png story_entry.png ...
#
# Optionally per-language: e.g. menu/zh-TW/event_entry.png. The configured language
# is preferred; a non-localized template is used as fallback.
